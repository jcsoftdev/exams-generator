## Contexto: por qué esta auditoría encontró lo que encontró

El hallazgo estructural es **drift de escala**. Entre el 2026-07-30 y hoy el banco central
pasó de 1,066 a 64,257 preguntas (`apps/api/src/db/data/collected/*.json`, 276 archivos).
Tres decisiones tomadas cuando el banco tenía ~71 filas visibles siguen vigentes y ninguna
tenía un guardián que avisara al invalidarse:

1. el árbol del banco no pagina,
2. el lazy-load de thumbnails está calibrado a "hasta 71 fetches paralelos",
3. el número de marketing está horneado en la landing.

El segundo hilo es documentación: no hay README raíz, el de `apps/web` es el boilerplate de
Angular CLI con instrucciones que no funcionan, y el design spec describe un diseño que el
código ya abandonó.
